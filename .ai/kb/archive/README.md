# Changelog 归档区

当 `.ai/kb/changelog.md` 超过 200 行或跨发版时,已发版条目整组迁到此处。

## 归档策略

- **触发条件**:changelog.md > 200 行 **或** 版本发布(如 v1.9.0 打 tag)
- **文件命名**:
  - 按版本:`changelog-1.8.x.md`(该版本全部条目)
  - 按时间:`changelog-2026H1.md`(上半年全部条目)
- **迁移范围**:整个 `## vX.Y.Z` 分组(含前言/遗留路线)
- **顶部保留**:当前开发周期 + 最近一个发版

## 现有归档

*暂无 — 首次归档将在 v1.9.0 发布后执行。*
